# PRD：通用 JDBC 驱动兼容性与回归测试框架

## 1. 背景和目标

现有项目已覆盖多个 JDBC API 测试场景，并具备 PostgreSQL、GaussDB、MySQL、Oracle、SQL Server 的基础支持。但数据库类型、驱动加载和测试资产仍存在核心代码耦合，结果分类、可追溯性、安全隔离和跨版本回归能力也不足以支撑数据库厂商持续使用。

本项目要演进为一个开源、可下载使用的 JDBC 驱动兼容性与回归测试框架。首要用户是数据库厂商和 JDBC 驱动维护者；应用开发者为次要用户。使用者提供自己控制的数据库实例与驱动，框架执行版本化的 JDBC 4.3（JDK 21）测试集，输出可共享、可比较的兼容性评估报告。

目标：

- 对 JDBC 4.3 标准接口及标准类型提供完整、可追溯的测试覆盖。
- 让新数据库以声明式数据库适配包接入，不修改 Java 核心代码。
- 让驱动团队可将评估和基线回归比较接入 CI。
- 在公司数据库环境中安全运行：专用测试命名空间、最小权限、显式破坏性操作确认、默认脱敏与本地存储。
- 通过 Python 启动器降低使用门槛，同时保留 Maven 高级入口。

本项目是基于自身版本化测试集的兼容性评估工具，不是官方 JDBC 认证，也不承诺完整覆盖 JDBC 规范的每一条要求。

## 2. 功能范围

### 2.1 测试套件与结果

- 以 JDBC 4.3 和 JDK 21 为首个正式兼容性基线。
- 覆盖所有 JDBC 4.3 标准接口区域；核心能力必须运行，可选能力必须有测试并依据适配包声明运行或跳过。
- 提供 JDBC 标准类型覆盖矩阵：常见类型为核心测试，ARRAY、SQLXML、ROWID、REF、STRUCT 等按声明能力执行。
- 每个测试用例拥有永久且唯一的稳定 ID，不依赖 Java 类名或方法名。
- 结果严格分为：通过、兼容性失败、能力跳过、已知差异、环境/执行错误、适配包不完整、清理失败。
- 已知差异必须绑定稳定测试 ID、适用数据库/驱动版本范围、原因、外部问题链接和复审期限；只有经维护者审核合入的声明才是正式已知差异。
- 默认串行执行，测试用例不自动重试；连接类预检可进行有限且可配置的重试。

### 2.2 数据库适配包

- 适配包以声明方式提供连接模板、能力声明、最小权限声明、测试命名空间策略、SQL 资产、已知差异和支持范围。
- 缺少任一 JDBC 4.3 测试区域所需资产或能力声明时，判定为“适配包不完整”并阻断运行，不能隐式跳过。
- 适配包声明数据库产品版本范围、驱动版本范围，以及实际验证过的精确数据库 × 驱动组合。
- 运行前读取 `DatabaseMetaData` 校验实际目标是否在适配范围内；范围外默认阻断。显式试验性覆盖可以继续，但结果不能用于正式基线或回归判断。
- 首发官方适配包：PostgreSQL、GaussDB、MySQL、Oracle、SQL Server。其他数据库可先以本地/试验性适配包运行完整测试。
- 本地适配包不修改 Java 核心即可接入，但在审核合入前，其报告必须标记为本地/试验性。
- 官方适配包随框架 Release 一起版本化发布；新官方适配包提交必须附脱敏的成功评估报告作为验证证据。

### 2.3 安全执行与预检

- 目标数据库始终由使用者或其组织提供和管理，框架不供应或自动创建目标数据库实例。
- 每次运行仅在用户指定或框架创建的专用、唯一 Test Namespace（schema 或等价命名空间）中操作。
- 未提供测试命名空间时，框架可创建唯一命名空间；账号无权使用或创建时，预检失败，不退回业务 schema 或表名前缀方案。
- `run` 前必须在本地配置中显式允许创建/删除测试命名空间；未确认时只执行预检。CI 通过受控配置显式开启。
- 每个官方适配包必须声明最小权限，预检应指出具体缺失权限。
- 清理失败必须作为独立、阻断 CI 的结果，保留测试命名空间及可定位信息供人工处理；框架不得扩大删除范围或自动清理历史遗留命名空间。

### 2.4 启动、报告与回归

- Python 启动器为默认入口，核心命令为：
  - `init`：交互式选择适配包并生成安全本地配置；密码仅引用环境变量，配置默认不纳入版本控制。
  - `run`：自动执行依赖预检、适配包与权限校验、测试、清理和报告生成。
  - `compare`：将当前评估与使用者认可的基线评估比较，输出新增失败、跳过或已知差异。
- Maven 保留为高级用户和 CI 的等价入口。
- Python 核心流程仅依赖标准库；基础 JSON/Markdown 报告不要求 `pip install`。
- 正式报告以版本化 JSON 为唯一权威格式；Markdown/HTML 为派生的阅读视图。
- 报告展示接口和类型的结果矩阵与计数，不生成单一“兼容性百分比分数”。
- 正式报告记录测试套件版本、适配包版本/修订、实际数据库与驱动版本、驱动 JAR SHA-256；不泄露连接信息。
- 仅相同测试套件版本的报告允许正式回归比较；测试套件变更后须重新建立基线。
- 驱动来源仅支持固定 Maven 坐标或本地 JAR，并校验和记录 SHA-256；不接受浮动“最新版本”或任意 URL 下载。

### 2.5 发布、文档与 CI

- 使用 Apache License 2.0。
- 每个正式版本发布 GitHub Release 包及 SHA-256；包内不分发第三方 JDBC 驱动 JAR。
- 内置官方适配包与用户显式指定的本地适配包均可使用；首版不自动从网络下载第三方适配包。
- 提供中英文 README 与快速开始文档。
- 正式支持 Linux、macOS、Windows；避免依赖 Unix shell。
- Python 启动器预检 Python、JDK 21、Maven，缺失时给出中英文可复制安装指引，不自动安装系统软件。
- Docker 保留为可选、一致性的框架运行环境，不作为默认入口，也不负责启动目标数据库。
- CI 中，新增兼容性失败、环境/执行错误、适配包不完整、预检失败、清理失败必须以非零退出码阻断；声明的能力跳过和正式已知差异不阻断。

## 3. 非功能要求

### 安全与隐私

- 不自动上传报告、基线或日志；仅写入用户本地或用户控制的 CI 工作区。
- 可共享报告默认脱敏密码、令牌、JDBC URL 参数、主机名、端口、数据库名和用户名。
- 完整 SQL、原始异常消息、堆栈等只写入本地诊断日志；对外报告仅保留脱敏错误类别、稳定测试 ID 和摘要。
- 所有破坏性数据库操作必须限制在 Test Namespace 内，且要求显式同意。

### 可复现性与可信度

- 正式评估必须包含完整的非敏感来源信息和版本信息。
- 基线由数据库厂商或驱动维护团队自行认可和保存；框架不认证或背书任何驱动。
- 支持范围与已验证组合必须分开呈现，不能将范围内未实测组合表述为已验证。
- 默认行为应保证可重复性优先于吞吐量。

### 易用性与兼容性

- 新用户可通过 `init → run → compare` 完成主流程。
- Python 核心启动流程零第三方依赖。
- 首发正式运行时为 JDK 21；更高 Java 版本仅可试验性运行，不能直接形成正式基线。

## 4. 验收标准

### 用户主流程

- 在 Linux、macOS、Windows 上，用户可下载 Release 包或源码，以 Python 启动器完成 `init → run → compare`。
- 用户使用 PostgreSQL、GaussDB、MySQL、Oracle、SQL Server 中任一官方适配包的一个已验证版本组合，能生成版本化、脱敏 JSON 报告及 Markdown/HTML 视图。
- 用户可将报告指定为自己的基线，并在相同测试套件版本下识别新引入的失败、跳过或已知差异。
- CI 对规定的阻断结果返回非零退出码，对正式已知差异和能力跳过不阻断。

### 安全与隔离

- 未显式同意创建/删除测试命名空间时，`run` 不执行破坏性操作。
- 无法使用或创建专用测试命名空间、权限不足、目标版本不匹配时，测试在执行 JDBC 用例前失败，并给出明确原因。
- 清理失败被显式记录、阻断 CI，且不删除命名空间外的对象。
- 可共享报告不包含凭据、连接地址及原始诊断内容。

### 扩展性与治理

- 新数据库可通过本地适配包运行完整 JDBC 4.3 测试，无需修改 Java 核心代码。
- 本地适配包结果明确标为本地/试验性，不能作为正式基线。
- 官方适配包包含支持范围、已验证组合、最小权限、完整测试资产与审核后的已知差异；新增官方适配包附带脱敏成功报告。

## 5. 不做什么

- 不做业务 SQL 验证、性能压测、数据库迁移验证或通用数据库运维工具。
- 不宣称官方 JDBC 认证、完整 JDBC 规范覆盖或对任何厂商驱动背书。
- 不把厂商专有 JDBC API 纳入跨数据库正式兼容性结果。
- 不供应、托管或自动启动目标数据库实例。
- 不在业务 schema 中运行，不以表名前缀作为无法创建测试命名空间时的回退方案。
- 不自动下载第三方适配包，不从任意 URL 下载驱动，不在 Release 包内再分发第三方 JDBC 驱动。
- 不自动上传任何报告或日志，不默认暴露连接与诊断敏感信息。
- 首发不支持默认并行测试，也不支持 JDBC 测试失败后的自动重试。
- 首发不把更高 Java 版本、未审核本地适配包或适配范围外的试验性运行结果作为正式基线或回归结论。
